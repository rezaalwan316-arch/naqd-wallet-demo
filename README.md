# Naqd demo app

A bilingual (English/Arabic) installable web app for trying the Naqd wallet flow.

## Try it locally

Serve this folder over HTTP, then open the local address in a browser. The app can also be hosted as a static site; HTTPS is required for install and offline support on most browsers.

The demo profile has a starting balance of 250,000 IQD. Demo payments reduce that balance and appear in activity. Data is stored in the browser's local storage; use **Reset** to restore the sample profile.

All payment data is simulated. This app does not connect to a bank, payment provider, camera, or remote server. The QR button opens sample merchants.
